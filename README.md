게임 소개
--
반복되는 전시관를 탐색하며 이상 현상을 관찰하는 3인칭 공포 게임입니다.  
매 루프마다 석상 Enemy의 활성화 유무가 달라지고 활성화된다면 5개의 석상 Enemy중 하나가 플레이를 위협합니다.  
Enemy가 있으면 나왔던 곳으로 다시 돌아오고, 없다면 반대면 통로까지 진행하는 형식입니다.  
정답이면 다음 층으로 진행하고, 오답이면 루프가 초기화됩니다.
